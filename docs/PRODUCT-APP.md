# Product workspace

Individual is available through wallet sign-in at `/app/individual`. Users can explore live protocol and market data, read their connected wallet balance, and use persistent simulated test deposits. Account details show the verified wallet address. Email/password authentication is retired.

Institution and the legacy `/developers` and monitoring entries currently show Coming soon. Their treasury, customer reporting and developer UI modules are retained for a later release. The built-in API sandbox remains separate from authenticated product balances; neither creates a real Partner API integration.

See [account operation](ACCOUNT-WORKSPACES.md) for authentication, migrations, data boundaries and tests, and [deployment](DEPLOYMENT.md) for proxy configuration.
